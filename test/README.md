# Test images

Put the PRD test set here, then run `npm run test:live` (see `scripts/live-test.mjs`).

- `inspirations/`: about 10 inspiration looks (JPEG or PNG)
- `selfies/good/`: at least one well-lit selfie; the first one is used for try-on
- `selfies/bad/`: poor selfies the quality gate should catch (dark, blurry, no face, two faces)

Only commit images you have the rights to use.
